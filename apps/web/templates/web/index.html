1Create customer POST /create_customer/

Creates a customer record. The returned id auto-fills step 2 (quote) and step 5 (list).

Format DD-MM-YYYY (also accepts ISO YYYY-MM-DD)
2Create quote POST /quote/

Prices a quote for a customer id + product type. Premium is computed server-side. The returned id auto-fills steps 3, 4, 6 and 7.

Numeric id from step 1
Seeded products; more can be added in the admin
personal-accident 1000–1000000 (def 200000); travel 1000–500000 (def 50000)
3Accept quote POST /quote/

Sends {quote_id, status: "accepted"}. Moves the policy quoted → accepted. Runs on the quote id below.

Numeric id from step 2
4Pay & bind POST /quote/

Sends {quote_id, status: "active", payment_method}. Moves the policy accepted → active and attaches a payment. Runs on the quote id below.

Numeric id from step 2
simulated_card succeeds instantly; invoice stays pending
5List policies GET /policies/

Lists every policy for a customer id. Optional filters narrow the set; leave them blank for all. This runs on the customer from step 1 — not a single policy.

Numeric id from step 1
Free-text: quote reference or customer name
GET /policies/
6Policy detail GET /policies/<id>/

Fetches one policy/quote by its id — customer, rating inputs and payment. Runs on the policy id below (auto-filled from step 2).

A quote and its policy share the same id
GET /policies/
7Policy history GET /policies/<id>/history/

Shows the ordered state transitions for one policy/quote id — the full new → quoted → accepted → active narrative. Runs on the policy id below.
